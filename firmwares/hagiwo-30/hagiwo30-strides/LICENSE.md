# CC0 1.0 Universal (CC0 1.0) Public Domain Dedication

Built for the HAGIWO #30 sequencer platform (Arduino Nano, SSD1306 OLED, rotary
encoder, six gate outputs). Strides is a maddie synths shell that hosts both
HAGIWO #30 sequencer engines and switches between them; those engines are
derived from HAGIWO's firmware for the platform, dedicated to the public domain
under CC0 1.0. This firmware is released on the same terms.
